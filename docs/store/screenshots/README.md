# Промокарточки Google Play

Текущий набор: шесть русских телефонных карточек `01-promo-home.png` …
`06-promo-sections.png`, 1080×1920, RGB24 PNG без alpha. Порядок, alt-тексты,
SHA256 и происхождение сохранены в [assets.json](assets.json), schema 2.

Крупные подписи Manrope ExtraBold, абрикосовый/кремовый/кобальтовый фон,
нейтральная скруглённая рамка и мягкая тень помогают быстро понять назначение
экранов. Это подготовленная с помощью ИИ композиция настоящих снимков, без
генерации или ретуши интерфейса. Подписи занимают 15,73% высоты карточки;
площадь интерфейса — около 60,49%.

## Источники

- `native/` — шесть настоящих снимков Android 136 (1.0.0), снятых на эмуляторе
  с демонстрационными данными. Home и дневник еды пересняты 05.11.2026,
  остальные четыре — 04.11.2026. Это отдельные состояния приложения.
- Исходный app commit: `ffd09050494a9404cbe7c9b3fd9ee86162c16ea1`;
  SHA256 AAB: `c0069cfd8cc2b8372bf8caa26505815fd1492b47cb0d6b553f8f92748aa6b260`.
  APK для снимков создан из этой AAB с bundletool 1.18.3 и подписан локальным
  Android Debug сертификатом. Это не APK, выданный Google Play.
- `compose.swift` — актуальный детерминированный AppKit-компоновщик. Он
  равномерно масштабирует целый native-снимок и скругляет его границу;
  подпись, фон, рамка и тень находятся снаружи интерфейса.
- `export-png24.py` — декодирует PNG с проверкой CRC, убеждается в непрозрачности
  alpha и записывает RGB24 без изменения RGB-пикселей скомпонованного растра.
  Карточка после масштабирования намеренно не побайтно идентична native-снимку.

APK/AAB, ключи, приватные журналы и снимки Console в этот каталог не входят.

## Повторный рендер

Нужен macOS с Swift/AppKit, Python 3 и зависимости проекта (`npm ci`). Шрифт —
`@expo-google-fonts/manrope` 0.4.2, `Manrope_800ExtraBold.ttf`. Из корня репозитория:

```sh
DRIFTORA_ARTWORK_DIR="$(mktemp -d)"
xcrun swift docs/store/screenshots/compose.swift \
  docs/store/screenshots/native "$DRIFTORA_ARTWORK_DIR/rendered" "$PWD"
python3 docs/store/screenshots/export-png24.py "$DRIFTORA_ARTWORK_DIR"
```

Результат — `upload/*.png` и `asset-verification.json` в отдельной папке;
`rendered/composition.json` содержит подписи, размеры и координаты. Скрипт
экспорта также поддерживает запуск без аргумента: тогда рабочей папкой
становится папка самого скрипта. При другом окружении AppKit/шрифтов растр
может отличаться: перед заменой проверяются новый рендер, хеши и читаемость.

## Замена в Console

Загружать только шесть верхнеуровневых `*-promo-*.png` в телефонную секцию
`ru-RU`, по порядку из metadata. Native-источники не являются промокарточками.
AI-декларация относится к новым композициям и проверяется отдельно для них.
Сохранённый Git-набор не подтверждает загрузку, review или публикацию в Play.

[Требования Google к ассетам](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en)
и [AI-декларации](https://support.google.com/googleplay/android-developer/answer/17262077?hl=en).
